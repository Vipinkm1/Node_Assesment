# Ecommerce Backend API

## Features
- JWT Authentication
- Product CRUD
- Cart APIs
- Admin Authorization

## Setup

1. Clone project

2. Install packages

npm install

3. Create .env file

-PORT=5000
-MONGO_URI=mongodb://127.0.0.1:27017/ecommerceDB
-JWT_SECRET=mysecretkey

4. Run project

npm run dev
